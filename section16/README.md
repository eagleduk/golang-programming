## pointer

- 메모리 주소를 확인(`&`)
  ```go
      a := 44
      fmt.Println(a)
      fmt.Println($a)
  ```
- 메모리 주소가 가지고 있는 데이터를 확인(`*`)
  ```go
      a := 44
      fmt.Println(a)
      fmt.Println(*&a)
  ```
- 값을 전달하고 리턴을 받지않고, 값의 주소를 전달하고 주소에 있는 값을 역참조 하여 변경(mutate)하면 데이터를 반환하지 않고도 값을 변경할 수 있다.
- 아주 큰 데이터를 전달하기에 부담스러울 때, 주소값을 전달하여 값을 활용할 수 있다.

- 함수의 리시버가 일단 값일 떄에는 함수호출시 `값, 포인터` 를 인자로 전달할 수 있지만, 리시버가 포인터일 경우에는 `포인터` 만을 인자로 전달할 수 있다.
