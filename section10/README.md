## Array

- 단일 타입 요소들의 연속
- 총 요소들의 수를 확정한다.
- `go 에서는 배열보다 슬라이스를 사용하라고 권장한다.`

## slice

- 같은 타입의 데이터를 묶는다.
- `[a:b]` 를 사용하여 슬라이싱이 가능하다. **(python: [slice])**
- slice 타입뒤에 `...` 을 추가하면 값을을 풀어 쓴것과 같다 **(javascript: [구조분해할당])**
- 슬라이스에서도 최초 길이를 지정할 수 있다(메모리에서 할당할 사이즈). 만약 해당 사이즈를 오바하면 처음 설정한 길이의 2배씩 총 사이즈를 자동으로 설정한다.
- _cap_ 메소드로 slice 의 할당 갯수를 확인할 수 있다.
