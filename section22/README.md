## Channel

> [!IMPORTANT]
>
> 채널에 반복문이든 뭐든 값을 많이 넣고 싶어도, [지정된 수량만큼 넣고] 값을 꺼낼 때 까지 기다린다.

- Channel 을 생성한다.
- Channel 에는 값을 넣고 꺼내올 수 있다.
  ```go
  chan <- [v]
  <-chan
  ```
- 값을 넣을 때는 `Goroutine` 을 사용하거나 생성시 넣을 값의 갯수를 추가한다.
- Channel 에 값을 넣으면 값을 꺼낼때 까지 블록된다.

#### 방향성(Directional)

- 일반타입(`chan [T]`) 수신 전문(`chan <- [T]` 송신 전문(`[T] <- chan`) 을 만들 수 있다.
- 일반 타입은 수신, 송신 전문에 할당(구체화)가 가능하지만 수신, 송신 타입은 일반 타입으로 구체화 불가능 하다.

#### close

- 반복문을 통해 많이 데이터를 넣을 수 있다.
  ```go
  close(c)
  ```
- close 하면 더 이상 값을 넣을 수 없다.
- close 한 채널을 읽으면 남아있는 값을 모두 읽을 때까지 멈춰있다가 모두 읽으면 false 를 반환한다.

#### range

- 채널을 닫을 때 까지 반복하며 기다린다.

#### select

- 채널에 값이 들어올 때 까지 기다린다.
