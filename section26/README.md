- [공식 사이트](https://go.dev/)

## go doc

```command
go doc [[패키지 명][.[심볼].[메소드]]]
```

- `go help doc` 로 도움말을 본다.
- `go doc` 은 현재 위치의 패키지를 본다.
- `go doc -http` 로 로컬 웹 문서 사이트를 설치 & 실행할 수 있다.

## pkg.go.dev
